Teilnahmebedingungen Loopi Run (Entwurf)

Bedingungen für die Teilnahme an der Aktion „Loopi Run“ der Loop Studio GmbH: ein Browser-Spiel, mit dem Sie sich einen persönlichen Rabattcode für das Loop-Studio-Abo erspielen können.

ENTWURF — zur Durchsicht für Christian Wenzel und Christian Arns

Dieser Text ist ein ENTWURF zur Durchsicht für Christian Wenzel und Christian Arns. Er ist keine Rechtsberatung und wurde von keiner Anwältin und keinem Anwalt geprüft. Bitte noch nicht veröffentlichen und nirgends verlinken.

Die Seite ist nicht verlinkt und für Suchmaschinen gesperrt. Zahlen und Fristen stammen aus dem Konzept zu Loopi Run (Rabattstufen 10 % und 20 %, 30 Tage zum Einlösen, 12 Monate Rabatt) und können sich noch ändern.

Offene Frage an Christian Wenzel und Christian Arns

Darf ein Spielcode mit anderen Testcodes oder mit der 7-tägigen Testphase des Abos (AGB, Abschnitt 04) kombiniert werden? Dazu steht heute nirgends eine Regel; dieser Entwurf trifft deshalb keine und verspricht nichts. Sobald Sie entschieden haben, kommt die Antwort als eigene Klausel in Abschnitt 05.

Zur Kenntnis: Der Server prüft nicht, ob ein Lauf tatsächlich gewonnen wurde; jede Person, die den Code-Abruf aufruft, kann einen Code erhalten. Die Mengen- und Missbrauchsgrenzen (Abschnitte 07 und 08) sind deshalb die einzige Absicherung.

01

Veranstalter

Veranstalter der Aktion „Loopi Run“ ist die Loop Studio GmbH, Hansaring 79–81, 50670 Köln, vertreten durch die Geschäftsführer Christian Wenzel und Christian Arns. Kontakt: contact@loopstudio.app. Die vollständigen Anbieterangaben finden Sie im Impressum.

02

Wer teilnehmen darf

Teilnehmen darf jede natürliche Person mit einem Mindestalter von 16 Jahren, wie es auch für die Loop Studio App gilt (AGB, Abschnitt 03). Die Teilnahme ist kostenlos und setzt weder einen Kauf noch eine Anmeldung voraus.

03

Persönlicher Einmal-Code

Wer einen Lauf gewinnt, kann sich im Spiel einen persönlichen Code holen. Je gewonnenem Lauf gibt es genau einen Code. Der Code ist ein Einmal-Code: Er lässt sich nur ein einziges Mal einlösen und gilt nur für das Loop-Studio-Abo unter app.loopstudio.app.

04

Rabattstufen

Es gibt zwei Stufen: 10 % Rabatt und 20 % Rabatt. Welche Stufe ein Code hat, hängt davon ab, wie weit der gewonnene Lauf geführt hat. Die Stufe steht fest, sobald der Code ausgegeben wurde.

05

Einlösen, Frist und Dauer des Rabatts

Der Code muss innerhalb von 30 Tagen nach dem Lauf eingelöst werden, in dem er ausgegeben wurde. Danach verfällt er.

Der Rabatt gilt für 12 Monate des Abonnements ab dem Abschluss. Danach gilt der reguläre Preis.

Ein Spielcode pro Konto: Je Nutzerkonto lässt sich nur ein Spielcode einlösen.

06

Kein Barwert, nicht übertragbar

Ein Code hat keinen Barwert. Er kann weder ausgezahlt noch gegen andere Leistungen getauscht werden und ist nicht übertragbar, also weder verkaufbar noch weitergebbar.

07

Begrenzte Menge, Beendigung der Aktion

Die Aktion ist mengenmäßig begrenzt: Pro Tag werden nur so viele Codes ausgegeben, wie das Tageskontingent erlaubt. Ist es aufgebraucht, gibt es an diesem Tag keine weiteren Codes. Ein Anspruch auf einen Code besteht nicht.

Die Loop Studio GmbH kann die Aktion jederzeit beenden oder ändern. Bereits ausgegebene Codes bleiben innerhalb ihrer Frist einlösbar.

08

Missbrauch

Wer Codes durch automatisierte oder massenhafte Anfragen beschafft oder dies versucht, wird von der Aktion ausgeschlossen. Erschlichene Codes werden gesperrt.

09

Datenschutz

Was beim Spielen und beim Abruf eines Codes verarbeitet wird, steht in der Datenschutzerklärung. Beim Abruf wird nur die erreichte Stufe (10 oder 20) übermittelt.

10

Anwendbares Recht

Es gilt deutsches Recht. Sind Sie Verbraucherin oder Verbraucher, bleiben die zwingenden Schutzvorschriften des Staates unberührt, in dem Sie Ihren gewöhnlichen Aufenthalt haben.
